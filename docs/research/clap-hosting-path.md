# CLAP hosting path for Halftrack

Research date: 2026-10-13 (local). Halftrack source: `9b598430221a2fb8ffa3a044d8c8207d347fbd76`; JUCE: `37c894f83d379179b2070d437ccd0f1cd9af9576`; Tracktion Engine: `07e2d674884293f1a6c8f35fb8d1b9f469ffa41f`, with the existing documented patches. This is source research and a proposed implementation plan. No CLAP adapter was installed, built, loaded, or tested; Halftrack still does not host CLAP.

## Recommendation

Implement a bounded original `juce::AudioPluginFormat` / `juce::AudioPluginInstance` adapter against the pinned CLAP C API, using the MIT CLAP helpers where useful. Keep it inside the existing Tracktion external-plug-in path. Start with generated effects and a MIDI 1.0 instrument, then expand declared capabilities as their tests pass. Do not treat a successful scan or a wrapped VST3 as native CLAP support.

The investigated repositories did not establish a mature, directly compatible JUCE host adapter. This is a bounded finding about the sources below, not proof that no other implementation exists. MIT source and Element's GPLv3-or-later source provide potential reuse routes with their notices retained; they are not all interchangeable with Halftrack's own license or architecture.

## Two registration points, one implementation

The pinned Tracktion parent manager adds default formats in `PluginManager::initialise()`. Halftrack exposes that manager through `Session::pluginFormats()`. Register the original format in `Session::Impl` after engine construction and before project construction/loading; use the same registration helper for dedicated test engines. [Pinned manager](https://github.com/Tracktion/tracktion_engine/blob/07e2d674884293f1a6c8f35fb8d1b9f469ffa41f/modules/tracktion_engine/plugins/tracktion_PluginManager.cpp), [current Session](https://github.com/jamescolasacco/halftrack/blob/9b598430221a2fb8ffa3a044d8c8207d347fbd76/src/Session.cpp).

The child scanner has a **different private format manager**, populated only with default formats in `PluginScanChildProcess`. Requests select a format by name; an unknown name currently produces an empty result. Parent-only registration would therefore look like a successful scan finding nothing. `Application::initialise()` enters `startChildProcessPluginScan()` before creating a Session. Proposed narrow change: an optional registration callback passed through that entry point to the child's constructor, applied before IPC initialization. Pin and test the affected Tracktion header/implementation/helper files; preserve the current scanner synchronization, fail-closed startup, retry and crash-blacklist corrections. There is no existing custom-format injection hook at this child boundary. [Pinned child scanner](https://github.com/Tracktion/tracktion_engine/blob/07e2d674884293f1a6c8f35fb8d1b9f469ffa41f/modules/tracktion_engine/plugins/tracktion_PluginScanHelpers.h), [current startup](https://github.com/jamescolasacco/halftrack/blob/9b598430221a2fb8ffa3a044d8c8207d347fbd76/src/Main.cpp), [current scanner patch](https://github.com/jamescolasacco/halftrack/blob/9b598430221a2fb8ffa3a044d8c8207d347fbd76/cmake/PatchPluginScanner.cmake).

Path discovery can run without loading libraries; actual entry/factory/instance inspection must stay inside the scanner child. Set `isTrivialToScan()` false. Support the standard platform directories and `CLAP_PATH`; on macOS load a `.clap` bundle's executable while passing its bundle path to entry initialization. Enumerate every factory descriptor. Preserve **both canonical module location and the complete descriptor ID** in discovery/project state: a 32-bit JUCE ID hash alone cannot be the authority when one library contains multiple plug-ins or hashes collide. Choose and test the serialization mapping before migration-sensitive projects depend on it. [CLAP entry](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/entry.h), [factory](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/factory/plugin-factory.h), [pinned JUCE format interface](https://github.com/juce-framework/JUCE/blob/37c894f83d379179b2070d437ccd0f1cd9af9576/modules/juce_audio_processors_headless/format/juce_AudioPluginFormat.h).

## Minimum adapter contract

The following are proposed implementation boundaries derived from CLAP revision `a47f6badb49d948fd009998f28309cdab78979c9`, not implemented features.

| Area | Required behavior before enabling the capability |
| --- | --- |
| Library and instance lifetime | Check ABI compatibility; balance successful entry init/deinit; retain the library and host data until every instance, editor and pending callback is gone. Destroy failed initialization correctly. Schedule main-thread creation/destruction and activation/deactivation separately from serialized symbolic-audio-thread start/stop/reset/process. Do not simply map all JUCE lifecycle methods to CLAP calls without checking their actual calling threads. [Instance contract](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/plugin.h). |
| Requests and threading | Implement restart, wake and main-thread callback requests. Publish audio-origin requests through preallocated queues/atomic flags; drain on the correct thread without callback-time allocation, locking or OS posting. Thread-check must describe each instance's actual serialized processing scope, including offline workers, rather than one fixed audio OS thread. Cancel deferred work safely on removal/undo/new/load. [Host callbacks](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/host.h), [thread contract](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/thread-check.h). |
| Audio and events | Preallocate audio views and bounded event storage. Discover ports while inactive; initially admit only tested mono/stereo layouts and one MIDI 1.0 note port, explicitly rejecting unsupported layouts/dialects. Preserve sample offsets and stable equal-time ordering; supply valid transport flags and monotonic steady time. Handle processing status, sleep and wake. Full CLAP note IDs/expression, MIDI2, multiple note ports and sample-timed modulation need additional engine interfaces; `MidiBuffer` alone does not represent them. [Audio ports](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/audio-ports.h), [note ports](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/note-ports.h), [events](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/events.h), [process](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/process.h). |
| Parameters and state | Keep stable CLAP parameter IDs, plain-value conversion, gesture boundaries and an explicit timing limit for JUCE parameter calls. Implement nonconcurrent process/flush delivery and correct inactive rescans. Persist opaque state including non-parameter data; handle stream short reads/writes and failed loads, dirty notifications and undo restoration. Do not invent parameter-save fallback when the plug-in lacks the state extension. [Parameters](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/params.h), [state](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/state.h). |
| Editor | Own the native view inside an `AudioProcessorEditor`; negotiate supported embedded Cocoa/Win32/X11 APIs, scaling, parent attachment, size constraints, visibility and destruction. Marshal thread-safe plug-in requests before touching native UI. Fall back to the generic parameter editor when embedding is unsupported. Timer/POSIX-FD services and other extensions must be implemented when advertised; do not return non-null stubs. [GUI contract](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/gui.h). |
| Latency, tails and rendering | Query latency during activation/while active, publish JUCE latency and rebuild compensation after the prescribed restart sequence; never silently change active latency. Keep tails separate from delay. Set render mode on the main thread, respect rejection/hard-real-time requirements, and test offline workers independently. Tracktion already observes processor latency changes and restarts its graph; that integration still needs an actual CLAP regression. [Latency](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/latency.h), [render](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/render.h), [tail](https://github.com/free-audio/clap/blob/a47f6badb49d948fd009998f28309cdab78979c9/include/clap/ext/tail.h), [pinned external processor](https://github.com/Tracktion/tracktion_engine/blob/07e2d674884293f1a6c8f35fb8d1b9f469ffa41f/modules/tracktion_engine/plugins/external/tracktion_ExternalPlugin.cpp). |

## Acceptance work before a support claim

Use original C-API fixtures so host and fixture do not share the same adaptation bug. These proposed tests extend the existing scanner/editor/latency harnesses; current VST3/AUv2 results are not CLAP evidence.

1. **Discovery and isolation:** multi-descriptor module, full-ID round trip and deliberate hash collision; invalid ABI/entry; exact parent/child registration. Constructor PID trace must show zero parent constructions during scans. Repeat real requests, startup-failure recovery, two deliberate child crashes with retry/blacklist, cancellation/hang/recovery, and platform path/bundle cases.
2. **Lifetime and threads:** bounded fixture trace of every lifecycle call; assert main/audio roles and nonoverlap through playback, offline export, restart, failed activation, sample-rate changes, removal and queued completion after undo/destruction. Check module unload occurs last. Audit owned callback queues for allocation/lock/syscall violations; functional tests alone do not prove race freedom.
3. **Signal and timing:** full-window finite PCM against gain/dry oracles; first/last-frame impulses and short exports with latency crossing block boundaries; dynamic-latency restart; finite/infinite tails and render-mode changes. Test sample-offset MIDI, same-key off/on, loop/seek/stop, processing sleep/wake and event-queue saturation with a documented failure policy.
4. **Persistence and UI:** parameter plus non-parameter state, malformed stream failure, save/reopen and one-step gesture undo/redo; custom/generic editor open/close/resize, removed instance, project replacement and late callbacks. Assert notifications do not erase unrelated redo or leave dangling UI.
5. **Cross-platform gate:** generated fixtures and scanner tests on macOS, Windows and Linux; separately record native editor checks and real vendor compatibility by version. Initially label support with the tested layouts/event dialects. Keep unsupported extensions explicit instead of claiming full CLAP parity.

The first concrete delivery should be child-isolated discovery plus deterministic gain processing/state through Tracktion, with honest format availability in the browser. Native editors, instrument events and the remaining rows become supported only after their respective tests. None of these measurements has been run for CLAP in this report.
