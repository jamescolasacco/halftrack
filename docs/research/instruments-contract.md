# Native instruments implementation contract

Halftrack implements four original instruments as native device kinds 24–27: Poly Synth, FM Synth, Drum Kit and Wavetable. They replace a MIDI track's built-in Halftrack Synth through `Session::setTrackInstrument`. The reference manual describes comparable workflows (Analog/Drift-style subtractive synthesis, Operator-style frequency modulation, drum synthesis, wavetable morphing; [instrument reference](https://www.ableton.com/en/live-manual/12/live-instrument-reference/), consulted 2026-10-20). It does not specify their algorithms, so every formula below is a Halftrack default. No reference binary output is used.

## Shared engine

`instruments::InstrumentDSP` (`src/Instruments.*`) holds 32 fixed voices, per-channel sustain pedal and pitch wheel, and a 16-key monophonic stack. Envelopes use a linear attack and exponential decay/release that fall 60 dB over their stated times. Parameter packets arrive through the native effect FIFO; rendering, note, controller and reset calls never allocate. Notes, pitch wheel (±bend range, separately normalized halves), CC64 sustain, CC120 all sound off, CC121 reset and CC123 all notes off follow the built-in synth's controller contract. Rendering is identical for any block partition.

- **Poly Synth**: two band-limited (PolyBLEP) saw/pulse/triangle/sine oscillators with octave, semitone, cents and pulse width; noise; off/LP12/LP24/HP12/BP12/notch state-variable filter with envelope (±5 octaves), key tracking, velocity and LFO; amp and filter ADSR; six-shape LFO to pitch, cutoff and tremolo; mono, legato (glide without retrigger) or 8/16/32 voices; 1–4 detuned, panned unison voices; velocity to amp.
- **FM Synth**: four phase-modulation operators (coarse ratio 0.5–48, fine, level and ADSR each), eleven routing algorithms from a serial stack to fully additive, feedback on operator D, optional low/high-pass filter, velocity to level, 4–32 voices. Carriers are averaged.
- **Drum Kit**: eight synthesized pads on GM notes 36, 38, 39, 42, 46, 45, 48 and 49 (kick, snare, clap, closed/open hat, low/high tom, cymbal), each with tune, decay multiplier, tone and level. The closed hat chokes the open hat with a 2 ms fade. Noise is seeded per hit, so renders are deterministic.
- **Wavetable**: two oscillators reading four shared tables (sine→triangle→saw→square, additive harmonics, narrowing pulse, hard-sync saw), each 16 frames × 1,024 samples with ten band-limited mip levels selected to keep every harmonic below Nyquist. Position morphs between frames, with LFO to position and pitch, filter, envelopes, unison spread and glide. Tables are built once on the message thread when the first Wavetable is created.

## Evidence

`tests/InstrumentsTests.cpp` checks: a sine voice equal to a closed-form quarter-scale sine; exact octave/semitone/cents pitch; saw harmonics following 2/(πk); linear polyphonic summing; voice-limit stealing; closed-form attack and release levels; the voice filter against the analytic state-variable magnitude; legato glide without retrigger; mono return to an earlier key; sustain pedal; maximum pitch wheel; closed-form tremolo; unison detune/spread; block-partition identity. FM tests cover a closed-form single operator, modulation index 1 producing Bessel J0/J1/J2 sideband amplitudes, ratio 0.5, feedback harmonics, linear velocity, voice limit and all eleven algorithms. Drum tests cover every pad, unmapped notes, kick settling near 50 Hz with tune +12 doubling it, decay, hat choke, level, velocity and block-partition identity. Wavetable tests cover the sine and square table ends, aliasing-free high notes and every table/position. Through the engine: an exported render matches the closed-form sine sample for sample; instrument changes undo/redo bit-identically, keep MIDI effects before and audio devices after the instrument, survive save/reopen and track duplication, and every instrument is audible. The real-time fixture exercises all instruments at parameter extremes with zero intercepted allocations.

Not implemented: sample-based instruments (Simpler/Sampler/Drum Rack pads), per-voice modulation matrices, MPE, oversampling, user wavetables, and any numerical comparison with the reference instruments.
