# Oscillator behavior contract

The reference is the installed 12.2.1 component inventory, with public behavior described by the [official instrument reference](https://www.ableton.com/en/live-manual/12/live-instrument-reference/#analog). Its oscillator section offers sine, saw, rectangular and white-noise choices. Rectangular width is adjustable, and its displayed maximum corresponds to a square. Those facts define a narrow implementation target; the manual does not provide a sample-level algorithm or establish an exact duty mapping between endpoints.

The isolated ARM64 instrument component has 991 declared entries; all produced outputs whose recorded hashes passed the independent verifier. The seven surviving public entry names include creation/destruction, processing, parameter assignment, reset, sample-rate and information functions. Processing and parameter assignment dispatch through C++ virtual methods. The initial wrapper output does not identify the full synthesis graph or justify translating the wrapper as a complete instrument. The native x86-64 comparison is a separate pending pass. Raw material remains in ignored local artifacts.

Halftrack's original implementation retains its existing waveform identities and sound at default settings. Values 2/3 add sine/noise, while waveform 1 gains normalized width with default 1. Its explicit working defaults are a 0–50% duty range and zero-mean pulse. Noise uses fixed per-voice state and deterministic initialization; it is not the reference noise sequence. Control changes retain voice phase, envelope and filter history. All patch controls go through the existing FIFO and native undo/persistence path. Disabled width UI communicates that it affects only pulse mode.

The implementation passes independently evaluated sample fixtures, block-size invariance, harmonic checks for width, finite/no-allocation processing, old-project defaults, invalid-command rejection, native-state sanitization and real UI/model save/reopen/undo tests. The first sine regression failed before implementation; all eight Mac suites pass afterward in 133.15 seconds. Noise fixtures use an independently evaluated direct-form bilinear low-pass rather than the production state-variable filter. Its original xorshift32 state advances by shifts 13/17/5; the seed is `0x9e3779b9 ^ (age * 0x85ebca6b) ^ (pitch << 8) ^ channel`, with 32-bit wrapping and a fallback of 1 for zero. Top-24-bit conversion maps to [-1, 1). This exact contract supports repeatable Halftrack renders, not reference equivalence. Paired reference audio remains unmeasured because the recorded Accessibility permission denial prevents automated reference interaction. Two oscillators, modulation/routing, additional filters and full instrument equivalence remain incomplete.
